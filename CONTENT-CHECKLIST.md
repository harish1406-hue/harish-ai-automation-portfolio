# Portfolio completion checklist

## Essential identity
- [ ] Confirm preferred professional title
- [ ] Add LinkedIn profile URL
- [ ] Confirm public email
- [ ] Decide whether to display phone number
- [ ] Add a professional headshot only if desired

## Every project
- [ ] Problem before automation
- [ ] Your exact contribution
- [ ] Architecture diagram
- [ ] Technologies used
- [ ] Guardrails and failure handling
- [ ] Dashboard or trace screenshot
- [ ] Honest measurable outcome
- [ ] Demo or repository link
- [ ] Client details anonymised where required

## Security review
- [ ] Remove `.env` files
- [ ] Remove API keys and tokens
- [ ] Remove private webhook URLs
- [ ] Remove customer names and documents
- [ ] Remove database credentials
- [ ] Review JSON workflow exports for embedded credentials

## Publish readiness
- [ ] Test mobile layout
- [ ] Test email and GitHub links
- [ ] Run `npm run build`
- [ ] Add custom domain
- [ ] Add favicon and social preview image
- [ ] Connect analytics
